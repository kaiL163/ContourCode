# КонтурКод

КонтурКод — платформа для алгоритмических соревнований. В проект входят веб-интерфейс на React и TypeScript, API на FastAPI, PostgreSQL и Judge0 для проверки решений на C++17.

## Запуск

Нужны Docker Desktop и Docker Compose. Из корня проекта запустите:

```powershell
docker compose --env-file .env.example up --build -d
```

Откройте [http://localhost:8080](http://localhost:8080). API доступно по адресу `http://localhost:8080/api`.

Файл `.env.example` содержит параметры для локального запуска. Перед запуском при необходимости замените значения на свои. Не используйте демонстрационные пароли и ключ подписи за пределами локальной разработки.

Для остановки контейнеров используйте:

```powershell
docker compose --env-file .env.example down
```

Данные PostgreSQL хранятся в Docker volumes и сохраняются после остановки. Для полного сброса локальных данных используйте `docker compose --env-file .env.example down -v`.

## Демо-вход

| Роль | Имя пользователя | Пароль |
| --- | --- | --- |
| Участник | `demo-participant-1` | `demo123` |
| Участник | `demo-participant-2` | `demo123` |
| Организатор | `demo-organizer` | `demo123` |

На странице входа можно выбрать профиль, чтобы автоматически заполнить форму.

Новые пользователи могут зарегистрироваться как участники на странице входа. После регистрации выполняется вход в созданную учётную запись. Регистрация организаторов через сайт не предусмотрена.

Профиль открывается нажатием на аватар или имя в шапке. В нём можно изменить отображаемое имя, аватар и навыки; никнейм для входа остаётся прежним.

## Режимы соревнований

Обычный контест открывается в разделе «Соревнования»: участник регистрируется, решает задачи и видит таблицу участников и историю контеста.

В разделе «Дуэль 1 на 1» или «Командный раунд» участник выбирает задачи и длительность, создаёт приглашение и передаёт ссылку второму участнику. Ссылка открывает страницу приглашения: участник может принять его или отклонить. Если нужно, сначала выполняется вход. Раунд начинается после присоединения второго участника. Регистрация в обычном контесте для этого не нужна. Отправки и результаты раунда хранятся отдельно от контестов.

На странице дуэлей доступна история раундов с результатами. В дуэли сравниваются количество решённых задач и суммарное время первых успешных решений; при полном равенстве объявляется ничья. В команде задача засчитывается один раз, если её решил хотя бы один участник. Оба участника могут досрочно завершить раунд, отметив готовность; до согласия второго участника готовность можно отменить. Отправленные решения сначала дожидаются проверки. При обрыве связи таймер не останавливается; участник может вернуться в раунд.

Миграции базы выполняются автоматически при запуске backend. Миграция 012 сохраняет существующие матчи и относит старые парные отправки к соответствующим матчам.

## Проверка решений

Решения отправляются из интерфейса в API и проверяются Judge0. Состояния отправок отражают результат проверки, включая принятое решение, неверный ответ, превышение времени, ошибку выполнения или компиляции.

Для локальной работы Judge0 настроен на Docker с поддержкой cgroups v2. Контейнеры Judge0 запускаются с повышенными привилегиями для изоляции процессов. Используйте проект только на локальной машине и не публикуйте его в интернете без отдельной проверки безопасности.

```powershell
cd frontend
npm ci
npm run dev
```

Vite доступен на `http://localhost:5173`; запросы `/api` проксируются на backend `http://127.0.0.1:8080`.
